# PUSHUP CHALLENGER

A mobile-first push-up challenge application.

## Features

- Mobile-friendly dashboard
- Player profile
- Push-up challenge setup
- 60-second, 2-minute, 3-minute and 5-minute rounds
- Camera access
- MediaPipe pose tracking
- Basic push-up rep detection
- Live timer and score
- Personal statistics
- Local match history

## Installation

1. Upload index.html, style.css, app.js and README.md.
2. Keep all files in the repository root.
3. Open Settings in GitHub.
4. Select Pages.
5. Choose Deploy from a branch.
6. Select main and /(root).
7. Save.

## Important

This is an initial prototype.

Camera-based rep counting needs real-device testing and calibration. The rival score is simulated. Online multiplayer, real accounts, global rankings and server-side verification are not implemented yet.

Camera access requires HTTPS. GitHub Pages provides HTTPS.
